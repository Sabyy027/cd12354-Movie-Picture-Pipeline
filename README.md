# Movie Picture Pipeline

## Project

**Movie Picture Pipeline** is a full-stack cloud application built and
deployed by **Sabeer Anwer Meeran S**.

The project contains: - **Frontend:** React - **Backend:** Flask API -
**Containerization:** Docker - **CI/CD:** GitHub Actions - **Cloud:**
AWS EKS and Amazon ECR - **Infrastructure:** Terraform - **Deployment:**
Kubernetes

## How I Completed the Project

I developed and tested the application locally, containerized the
frontend and backend using Docker, and used Terraform to provision the
AWS infrastructure.

I created GitHub Actions workflows for: - Frontend CI/CD - Backend
CI/CD - Linting and testing - Docker image build and push to Amazon
ECR - Deployment to Amazon EKS

The application was then deployed to Kubernetes and verified using the
AWS LoadBalancer endpoints.
